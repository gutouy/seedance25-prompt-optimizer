# Seedance 2.5 Core Rules

## Base Formula

主体 + 动作或事件 + 场景与环境 + 视觉风格 + 运镜或切镜 + 声音

## Optimization Principles

1. Preserve user hard constraints first.
2. Add only low-risk details that improve generation.
3. Make emotions observable.
4. Make camera language executable.
5. Keep continuity stable.

## Auto Enrichment

Allowed additions:
- movement details
- environmental reactions
- lighting and material response
- camera path
- sound design
- continuity constraints

Avoid inventing:
- unrelated plot
- identities
- exact subtitles
- product specifications
- unsupported facts

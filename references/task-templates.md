# Task Templates

## Multi Reference

Always map:

素材职责 → 主体映射 → 场景调用 → 保持内容

Example:

@图片1用于人物外貌和服装，不采用图片背景。
@视频1用于动作和镜头节奏，不采用视频人物身份。

## Long Video

Use:

阶段一：开始状态 / 主要事件 / 结束状态
阶段二：承接状态 / 主要事件 / 结束状态

## Video Editing

Define:

- unique source video
- edit target
- edit range
- unchanged content

## Extension

Keep boundary frame, movement trend, sound and spatial relationship continuous.

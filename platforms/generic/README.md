# Generic agent adapter

Use `system-prompt.md` with any agent builder that accepts a system prompt, developer instruction, persona prompt, or persistent agent instruction.

The prompt is self-contained and does not require the agent to read other files.

Suitable targets include custom LLM wrappers, low-code agent builders, internal chat agents, and tools that do not natively implement the Agent Skills filesystem standard.

For the human-readable, annotated version, see:
